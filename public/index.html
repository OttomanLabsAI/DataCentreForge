Examples
Placing an example replaces the drawing, after asking unless the drawing is empty; Wipe clears it first if you would rather start from nothing. Undo brings the previous drawing back.
Layers
Every chamber, run and obstacle belongs to a layer, like a Revit workset. A dynamic layer is routed by the tool and its manholes can move; a static layer stays as it is — its manholes stay put, modelled paths are kept, and anything else is laid without avoidance and then fixed — and dynamic runs keep clear of it. A layer's setting takes effect on Update routes. New elements go to the active layer.
Models
Each model is a layer. Untick a model to hide all of it, or hide only its manholes, conduits, encasement or obstacles; Select takes everything shown on the model as the selection. A static model's manholes, conduits and encasement are keep-outs for every dynamic run, shown or hidden.
