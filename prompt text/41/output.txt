Version 41: layers like worksets, an Encase button, and one Update routes button for all of it.

Every chamber, run and obstacle now belongs to a layer, like a Revit workset, and a Layers window in the Manage group lists them with their counts. Each layer can be renamed, shown or hidden — a hidden layer is neither drawn nor picked — made the active layer that new chambers, runs and obstacles go to, or deleted, which sends what was on it to the Drawing layer; the selection can be moved to any layer with a press. Each model placed from the Examples window or brought in from Revit lands on a layer of its own, named for the model and static or dynamic as chosen there, and its modelled paths are kept with its runs so it can go static again later. A layer is dynamic or static, and that is where the setting lives now: a static layer's manholes stay put at once, and the one Update routes button does the rest for every layer together — a static layer's runs are fixed as they stand, a modelled path kept and any other run laid without avoidance and then fixed, while a dynamic layer's runs are routed afresh round everything static and encased. Each layer says how many of its runs are waiting for Update. The drawing's file carries the layers, and an older file's static models come back as static layers.

An Encase button now sits in the Create group. It puts the encasement box on the selected runs, on the runs of the selected chambers, or on every run when nothing is selected, and pressed again on the same runs it takes the box off; a spec with no encasement offset is given 100 mm the first time one of its runs is encased, and the status line says so. An encased run is avoided by its box itself: a neighbouring run keeps its own clearance from the box rather than from the conduits, two encased runs keep box to box, and obstacles and the ground cover allow for the box.

Hold ctrl (or ⌘) with shift while dragging and the drag keeps to the grabbed chamber's own axes, along or across it however it is turned, snapping along that line; the hint under the ribbon names it. Shift alone still holds a world line.

Verified in a driven browser: the Encase button encasing every run when nothing is selected and giving the LV and fibre specs a 100 offset, taking it off again on a second press, encasing one selected run alone and the runs on a selected chamber; two runs keeping 800 apart plain, 900 with one encased and 400 box to box with both; the Layers window opening with the Drawing layer active and dynamic, a new layer taking the next chamber, a selection moved to it, the layer set static holding its manhole at once and counting its run as waiting, Update routes fixing that run on its own route while the dynamic one stayed free, the layer set dynamic and updated routing it again with the manhole free, a hidden layer neither drawn nor picked, and a deleted layer returning its elements to Drawing; the MV model added static landing on a static MV layer with 77 fixed runs, set dynamic and updated routing its banks again, and set static and updated putting every bank back on its modelled path; the file carrying the layers and bringing them back, and an older file's static chambers becoming a static layer named for their model; a ctrl+shift drag of a chamber turned 30° moving along whichever of its own axes the drag leaned to, plus the batteries from versions 14 to 40, all passing with no console errors. Two new ribbon buttons made thirteen, which wrapped the header to two rows on an iPad on its side and on a laptop screen, so the ribbon is retuned: the subtitle folds away below 1,400 px and the buttons tighten below 1,140 px, and the header keeps one row from 1,024 px up. Four earlier checks were brought to the new semantics: static chambers now come from a static layer, a run has its box once encased, a neighbour keeps its own clearance from the box, and the ribbon has nine window buttons.
