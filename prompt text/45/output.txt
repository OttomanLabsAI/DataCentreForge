Version 45: a run lists only what stands in its way, and one control sets them all.

A run's Obstacles panel no longer lists the whole site. It lists what that run actually meets: everything its route passes — or, while it has no route, its straight line from one entry to the other — within its own width, the clearances and half a metre of slack, together with anything it has already been given a choice for, so a decision never disappears from view. Its own two manholes are never in the list. On the MV site, where a hundred and fifty-two static elements stand, the run in your screenshot now shows the ten it meets: two static manholes and eight static conduit banks, named as you wanted them — MVF-01·C → MVF-02·C · static conduits beside LVV-05 · static manhole.

At the top of the list sits one control: All ten in its path. Choose around, over or under and every listed element takes it at once; choose the default and they all go back to it. The status line says how many were set. Each row still has its own choice beneath, so the quick pass can be made in one press and then refined where a particular bank wants something different.

Verified in a driven browser: a drawing of seven static elements where only the bank across the way is listed, the far pair and the distant manhole left out; the panel showing that one row with the set-them-all control offering default, around, over and under; a static manhole moved beside the line joining the list; one press setting both to under and the run crossing both, with the status line naming the count; one press putting them back to their defaults and the run blocked again as before; and on the MV site a hundred and fifty-two elements narrowing to the ten the run meets, manholes and conduit banks together, with the panel listing exactly those, plus the batteries from versions 14 to 44, all passing with no console errors. One check from version 44 expected the whole static model in the panel; it now expects the bank across the run's way, since the two manholes of that drawing sit nine metres off its line.
