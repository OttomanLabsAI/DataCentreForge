Version 48: a run only deviates for what is really in its way.

You were right: nothing was in its way. Since the last version a run passes what it meets underneath, and that was being read too literally in two places. A conduit already running clear above a static bank, its clearance and all, was still counted as having to dive under it. And where the dive could not be made — the ground above, the chamber's own base below — the run refused instead of doing the obvious thing and keeping clear of the bank in plan. The message then named something the run never came near, because the only route that met it was one the tool had tried and thrown away.

Both are mended. Whatever a run already clears, above or below, is left alone: no dip, no note, nothing to answer for. Where there is truly no room to cross, the plan is laid again with that bank or manhole as a keep-out and the run is routed clear of it, saying on itself what it was kept clear of and why; only when that cannot be done either does it refuse, and then it names what stopped it, as before.

The run you circled is one of them. LV6/Z3 to LV7/Z3 is placed now — 6.04 m, straight and level — and the MV bank it was blamed on sits in its obstacle list marked not met.

Across the site the difference is plain. With the MV model static, 146 of the 164 banks are placed where 132 were; with the LV model static, 147 where 145 were. Eight of the MV-static ones are routed clear of something they cannot cross and say so. The eighteen still refused are honest: two services wanting the same depth in the same corridor, each naming what it could not get past.
