It was already in the spec editor as "Min straight", but as one blunt number that the bend tangents could eat entirely — so it wasn't really a minimum. Now it's two, and it's enforced properly.

Minimum straight in each spec:

off chamber face — the straight leaving and entering a chamber
between bends — the leg between two consecutive fittings

These are now measured as straight pipe, not centreline segment. Before, a 600 radius bend on a 500 segment consumed the whole thing and you got no straight at all. The router now sizes each segment to carry the bend tangents on top of the minimum, so the straight you ask for is the straight you get.

It runs two passes. The first insists on the full bend radius clear of the minimum straights — that's what you'll normally get. Only if nothing fits does it try again with radii cut back, and then it names which bends had to give: "bend 2 — R600 will not fit beside the minimum straights, cut to R380".

The run panel now reports Straight pipe — the clear length of each straight after the bends are taken out, which is the number you'd actually cut to. Export carries both straights (centreline segments) and straightPipe.

Defaults on the seeded specs are 500/750, 400/600 and 300/450. Worth knowing: raising these pushes runs toward more bends, since a tight offset that a shallow 22.5 could once absorb no longer has room for the legs — the demo run past the obstacle now holds 500 off each face and 5624 between bends at full R600.
