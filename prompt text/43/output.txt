Version 43: the spacing comes to the array panel.

A run's Array & level panel now carries the centres it is laid on, beside the picture of its section: Spacing across and Spacing down, with the cluster's own line reading, for instance, 3 + 2 · 600×300 · L0. They are not new numbers. Across is the spec's array spacing and down is the Z spacing of the run's two manholes — the same values the Specs and Chambers windows have always held, which keep their fields; set either place and both show the change, and the note under the two fields says exactly where each one lives. The spacing takes effect everywhere at once: the face's grid, the picture, the elevation, the 3D view and the encasement box all follow, and a face is still laid on the largest across-spacing of the runs it carries, so runs sharing a face stay on one grid. A static run's two fields are fixed, as its spec and depth already were.

Verified in a driven browser: the two fields reading 600 and 300 from the MV spec and the manholes, with the cluster line and the note naming both homes; the encasement measuring three conduits at 600 across and two rows at 300 down; widening across to 900 widening the face grid and the box; deepening down to 450 dropping the second row in the elevation and in the 3D centrelines and heightening the box; both edits landing on the spec and on both manholes, with the Specs and Chambers windows showing the new numbers; the spec set back from its own window and the run's field following; a second run on a wider spec pulling the shared face grid to 1,000 while its neighbour keeps its own 600; the drawing's file carrying both centres and an import restoring them; the MV model's banks taking the centres of the specs it creates; and a static run's fields fixed, plus the batteries from versions 14 to 42, all passing with no console errors. While testing I found that re-rendering the panel as a field changed rebuilt the fields under the cursor, so the cluster line is now updated in place instead, as the rows field already did. Two checks from version 37 read that line and were brought to its new shape.
