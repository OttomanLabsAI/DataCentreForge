Version 35: one custom bend, and only where the angle demands it.

Two manholes set at an angle to each other that the standard fittings cannot make are now joined all the same. The run takes one custom bend that makes up exactly the difference, and only when no combination of up to four standard bends can. Its angle is whatever is left of the mismatch after the fewest standard bends that bring it within a right angle, so a chamber turned 32.9° from its neighbour gets a single 32.9° fitting, one turned 4.9° gets a single 4.9° fitting, and one turned 122.9° gets a standard 90° and a 32.9° custom. Faces 45° apart, or 33.75° apart where 22.5° and 11.25° can make it, still get standard fittings exactly as before, and a run that cannot be made even with its custom bend says so and names the angle it tried.

Custom bends are kept to a minimum. A route with one costs the router more than any number of extra standard bends, so it never reaches for a custom fitting while a standard answer exists, and a run never carries more than one. When a run with a custom bend also has to steer around an obstacle, the detour is made of standard bends only: the custom fitting stays fixed at the angle the faces demand and the standard bends around it do the work of getting past the obstacle. Every custom fitting is flagged on the run, in its Check this run list and in its bend list, as a custom fitting made to suit the angle between these faces. The long section is untouched: vertical bends are standard fittings as before.

Verified in a driven browser: faces 32.88° apart getting one custom bend of exactly 32.88° and nothing else, faces 4.86° apart getting a single 4.86° custom, faces 45° apart and 33.75° apart staying standard, faces 122.88° apart getting a standard 90° and one 32.88° custom, an obstacle in the way of a custom run producing a standard detour with the custom bend still 32.88°, a standard angle with an obstacle never borrowing a custom bend, two chambers 32.88° apart on the drawing joining with one custom bend that the run flags and the bend list names, the section unaffected, plus the batteries from versions 14 to 34, all passing with no console errors.
