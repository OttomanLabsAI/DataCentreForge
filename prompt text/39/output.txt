Version 39: static models stay as modelled, and dynamic ones work round them.

Every sub-model in the Examples window now has a choice beside its Add button: dynamic or static. Dynamic is what you had: the tool routes the model's runs and its manholes can be moved. Static places the model as it is modelled: its manholes stay where they are — a drag selects one and the status line says it is static — and its conduit banks keep the centrelines read from the IFC, at their modelled depths, meeting each face where the model put them; they are never re-routed, carry none of the tool's fittings, and their panel shows the array, spec and depth as modelled with nothing to change. Every dynamic run treats a static bank as a keep-out and bends round it, whatever the pipe-avoidance setting says, and two static banks are left as modelled even where they sit close. Any number of models can be static and any number dynamic; re-adding a model with the other choice switches it in place, so a static MV model can be made dynamic again and its banks are routed by the tool from then on. Place site honours the choice made for each model, the drawing's file carries the static runs with their paths, and Undo covers all of it. The MV example was rebuilt to carry each bank's modelled centreline, averaged across its conduits; the LV model has no conduits, so static there means its manholes stay put.

Verified in a driven browser: a static run built from a six-point centreline keeping every point, its plan and laid lengths and no warnings; a dynamic run whose straight line crossed it bending four times to keep five metres clear, with pipe avoidance on and off alike; the static run meeting its face where the model put it and its chamber refusing to be dragged, the status line saying why; the static run's panel with spec and depth fixed, no slots to click, no Update line and a route that says static; the export carrying the static flag and path and an import bringing them back; the dynamic and static choice on each sub-model; the MV model added static giving 75 static chambers and 77 static runs, every one on its modelled centreline; a run drawn by hand between two of its manholes staying dynamic; the model re-added dynamic freeing its chambers and routing its banks again; and the LV model added static holding its 105 manholes still while the dynamic MV ones stayed free, plus the batteries from versions 14 to 38, all passing with no console errors.
